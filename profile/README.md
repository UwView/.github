## 🔑 Key Features & Architecture

### 📄 1. Memory-Mapped Large File Handling

* **Lazy Rendering:** Uses memory mapping to render only the visible viewport on screen rather than pulling the entire file into RAM.
* **Instant Opening:** Opens multi-gigabyte files immediately, allowing instantaneous scrolling through the document from second one.

### 🔍 2. Background Indexing & Sparse Indexing

* **Non-Blocking Indexing:** Generates file structure indices silently in the background without locking the user interface.
* **Sparse Index Memory Model:** Uses a compact line-resolution index to map exact line numbers and byte offsets while maintaining a low memory footprint.

### ⚡ 3. Fast Searching & Navigation

* **Immediate Search Availability:** Search across text strings, timestamps, error codes, and identifiers right after opening, even while background indexing finishes.
* **Smooth Viewport Scrolling:** Eliminates scroll lag by dynamically streaming content lines as the scrollbar moves.
